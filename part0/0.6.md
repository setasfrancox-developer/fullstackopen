# Exercise 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User writes a new note and clicks Save

    Note right of browser: JavaScript handles the form submission

    Note right of browser: A new note is created with content and date

    browser->>server: POST /exampleapp/new_note_spa
    Note right of browser: Content-Type: application/json
    Note right of browser: Note data sent as JSON

    activate server
    Note right of server: Server saves the new note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note right of browser: JavaScript adds the note to the list
    Note right of browser: Browser renders the updated notes without reloading
```
